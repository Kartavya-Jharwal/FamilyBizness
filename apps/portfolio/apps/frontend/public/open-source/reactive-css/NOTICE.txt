FamilyBizness adapts its registered-number transition, digit reels (0–9 plus carry zero), modulo/carry geometry, edge mask, motion blur and reduced-motion pattern.

The host React form/input architecture implements click, hold/cancel, keyboard, drag, min/max/step and disabled semantics. The actual existing input remains the form field; refs, locale formatters and validation are retained. The external Reactive CSS runtime, global body/theme styles, tutorial panels and external handwriting font are not loaded into the application.
