# Portfolio Prototype

Combined static UI used by the parent preview shell. Product facts remain in the parent's [Identity](../../docs/00%20-%20Canonical/Identity.md).

```powershell
bun install --linker hoisted
bun run dev
bun run donor:smoke
```

From the parent repository, `bun run donor:verify` runs the smoke suite, builds the complete static artifact and verifies product-brand removal and original legal records. The [combined pass sign-off](../../docs/02%20-%20Strategy/Donor%20-%20Combined%20Pass%20Sign-Off.md) owns scope, evidence and remaining limits.

Original credits and licenses are retained in [NOTICE.md](NOTICE.md), [LICENSE](LICENSE), [TRADEMARKS.md](TRADEMARKS.md) and the public open-source records. Sample data and scripted assistant behaviour are local; no model or financial service is connected.
