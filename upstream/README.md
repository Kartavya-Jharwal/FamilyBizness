# Upstream design references

This folder records the origins of shared design foundations. The live global tokens have one home: [packages/tokens/tokens.css](../packages/tokens/tokens.css).

The initial foundation is extracted from the local Wealthfolio donor's Classic theme: [theme definition](../apps/portfolio/apps/frontend/src/themes/definitions/classic.css), [font and type setup](../apps/portfolio/apps/frontend/src/globals.css), and [theme attribution](../apps/portfolio/apps/frontend/src/themes/NOTICE.md). Classic retains Flexoki colours, with Wealthfolio's financial/chart adaptations. The donor's [licence and notice](../apps/portfolio/NOTICE.md) remain with its adapted source.
