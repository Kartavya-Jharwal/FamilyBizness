# Cases and Constitution Management

FamilyBizness supports independent family cases through the existing Portfolio profile system. Golden Bird is one selectable assignment example; it is not the platform's fixed family or final constitution.

## Create a family case

Choose **Add profile**, enter the profile/case name and optional business name, then select either **Blank family case** or **Golden Bird assignment example**. A blank case creates identity and empty source/constitution records. Its analytical workspaces can show labelled examples until the family saves its own inputs; those examples do not count as saved case records. The optional example copies records into the new profile, so subsequent edits remain independent.

Profile creation and initial module writes use the existing validated case boundary with rollback on storage failure. Existing profiles and case data are not overwritten.

## Adopt and select constitutions

In **Family business → Constitution linkage**, the Constitution library holds multiple named constitutions per profile. Add a constitution, start explicitly from the Golden Bird example, or import a validated library file. Record the cash and decision clauses, reviewer, currency and supported numerical parameters. Adopting a revision validates allocation totals, thresholds and reviewed source references, then freezes the selected source snapshot.

Selecting another constitution changes the active source pack and the parameters consumed by cash and voting checks. Pausing constitutional checks leaves the library intact. The generic rule-draft editor remains available for other supported policy types.

Current supported parameters cover funding horizons, fixed-cost reserve months, compliance years, the remaining-cash allocation, eligible owner-right thresholds, voter quorum, Board recommendation fraction and outside-branch representation. Owner voting inputs can be edited through the existing validated table. A case without an adopted constitution does not inherit Golden Bird's thresholds or sample capital.

## Connected operation and persistence

Source edits invalidate the active binding until the reviewed revision is adopted again. Check results use the selected pack's source IDs and currency. The dividend action validates a saved funding entity and matching currency, then atomically updates the existing financial forecast and saved investment-spending scenario. A decision review uses the current case business identity and the existing office log.

The constitution library and both check-input records participate in portable case export/restore. Independent profile keys keep families separate; the full board report evaluates the active constitution's actual parameters. Older Golden Bird packs migrate only when their adopted clause snapshots match, rather than applying the sample to arbitrary families.

## Stewardship home

The family workspace remains the one stewardship home. Saved records supply statement cash, overdue responsibilities, succession funding gaps, continuity readiness and active constitution status. An owner/persona view filters the same obligations used by Calendar and the board report. Each summary links to its source workspace; missing inputs remain visibly unpopulated. Stewardship findings are available through the shared review route.
